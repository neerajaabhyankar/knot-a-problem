## 1. Title and abstract

## 2. Definitions to write down, in this order

Keep these tight. Each is one or two sentences.

1. **Link.** A smooth embedding of a disjoint union of `n` circles in `S³`;
   `L = K₁ ⊔ … ⊔ Kₙ`. The `Kᵢ` are its **components**.
2. **Equivalence.** Ambient isotopy of `S³`. State explicitly whether component
   labels are remembered — **they are**, because condition (i) is a statement
   about *every* 3-subset and we need to index them.
3. **Sublink.** For `S ⊆ {1,…,n}`, `L_S = ⋃_{i∈S} Kᵢ`.
4. **Unlink** `Uₙ`: `n` components bounding disjoint embedded discs.
5. **Borromean rings** `B`: the 3-component link `L6a4`. Fix one diagram in a
   figure and call *that* the definition, so later claims have a referent.
6. **Linking number** `lk(Kᵢ,Kⱼ)`. Standard; cite.
7. **Milnor's triple invariant** `μ̄(ijk)`. Define only in the case we use:
   all pairwise linking numbers zero, in which case `μ̄(ijk) ∈ ℤ` with no
   indeterminacy, and it is alternating in its three indices. Cite Milnor.
   State `μ̄(123) = ±1` for `B`, with the sign fixed by the chosen diagram.
8. **Symmetry group of an embedding.** For `G ≤ SO(3)`, an embedded link
   `L ⊂ ℝ³` is **G-symmetric** if `g(L) = L` setwise for every `g ∈ G`. This
   induces `ρ : G → S_n` by `g(Kᵢ) = K_{ρ(g)(i)}`.
9. **T**: the rotation group of a regular tetrahedron, `T ≅ A₄`, `|T| = 12`:
   the identity, eight 120° rotations about the four vertex-to-opposite-face
   axes, three 180° rotations about the axes through midpoints of opposite
   edges.

> **Note on (2).** Ambient isotopy of *embeddings*, not of link types, is what
> the symmetry condition lives on — symmetry is a property of a particular
> embedding, not of a link type. Say this once, clearly. A link type "has
> tetrahedral symmetry" iff **some** representative embedding does.

## 3. The problem

> **Problem.** Find a 4-component link `L = K₁ ⊔ K₂ ⊔ K₃ ⊔ K₄ ⊂ ℝ³` with
> **(i)** `L_S ≅ B` for every 3-element `S ⊂ {1,2,3,4}`, and
> **(ii)** `L` is `T`-symmetric for some `T ≤ SO(3)` isomorphic to the
> tetrahedral rotation group, with `ρ` injective.

Two things to say immediately after stating it, both of which are small and both
of which a careful reader will otherwise ask:

- **Pairwise unlinkedness is not a third condition.** Every 2-subset sits inside
  a 3-subset; by (i) that 3-sublink is `B`; every 2-component sublink of `B` is
  `U₂`. So (i) ⟹ every pair is unlinked. *State the problem with two conditions
  and note this.*
- **"ρ injective" already forces transitivity.** The only subgroup of `S₄`
  isomorphic to `A₄` is `A₄` itself, and `A₄` is transitive on 4 points. So we
  do not need to assume the four components are permuted transitively; it is a
  consequence. (One line, worth including — it is the difference between an
  assumption and a lemma.)

Consequence to record: by orbit–stabiliser, `Stab_T(Kᵢ)` has order 3 and is
generated by a 120° rotation about one of the four axes. **Each component is
individually invariant under a 3-fold rotation.** This is the single fact the
construction exploits.

## 4. Results to state

- **Theorem A (Existence).** There is a link satisfying (i) and (ii). Explicit
  coordinates given; the symmetry group has order 12.
- **Proposition B (The triple invariants).** The constraints that (ii) imposes
  on `μ̄(ijk)` leave a 1-dimensional solution space, spanned by `(−1,1,−1,1)`.
  So they are consistent with `|μ̄(ijk)| = 1` on all four triples, and the signs
  are determined up to one global sign. *A necessary condition passing, not a
  construction — say so.*
- **Proposition C (Convex planar components are impossible).** If every `Kᵢ` is
  a convex planar curve, no link satisfies (i) and (ii). Moreover each `Kᵢ` is
  then forced to lie in a plane perpendicular to one of the four 3-fold axes.
- **Remark D.** Convexity in C is essential, and the planar case without it is
  open. (§5.5.)
- **Proposition E (contrast, optional).** No 4-component **Brunnian** link with
  a non-vanishing length-4 Milnor invariant admits a symmetry fixing one
  component and cycling the other three. Include only if it fits in 4 pages;
  otherwise it is the seed of the companion note.

## 5. Lemmas, with proofs and status

### 5.1 Pairwise unlinkedness is implied — **done, trivial**
As in §3. Two lines.

### 5.2 The face/vertex correspondence — **done, needs writing**
Label faces `F₁…F₄` of a regular tetrahedron and vertices `v₁…v₄` so that `vᵢ`
is the vertex *opposite* `Fᵢ`. Then the three faces meeting at `vₖ` are exactly
`{Fᵢ : i ≠ k}`. Hence `S ↦ v_{complement(S)}` is a `T`-equivariant bijection
from 3-subsets of components to vertices.

**Why it matters, and this is the whole point of using a tetrahedron:** `T` is
transitive on vertices, so the four instances of condition (i) lie in a single
orbit. Verifying one verifies all four. *Credit Kyle Miller here.*

### 5.3 Stabilisers and the generation principle — **done**
`Stab_T(Kᵢ) = ⟨r_i⟩`, `r_i` a 120° rotation. Conversely, given any closed curve
`K` invariant under `r₁`, the four images `{g(K) : g ∈ T/⟨r₁⟩}` form a
`T`-symmetric 4-component configuration, for *any* such `K`. So the symmetry is
a property of the construction, not of the particular curve, and the search
space is "one `r₁`-invariant curve".

State this as a lemma. It is what makes Theorem A's verification finite and it
is what makes the symmetry exact rather than approximate.

### 5.4 Convex planar components are impossible — **done, proof is clean**

Write it in four steps.

**(a) The plane is forced.** A planar simple closed curve spans a unique plane
`P`. If `r_i(Kᵢ) = Kᵢ` then `r_i(P) = P`. A 120° rotation about an axis `a`
preserves a plane `P` only if `P ⊥ a` (a plane containing `a` is moved to a
different plane containing `a`, since 120° ≢ 0 mod 180°). So `Pᵢ ⊥ aᵢ`.

**(b) The half-turn acts on the intersection line by point reflection.** For
`i ≠ j`, `Pᵢ ∦ Pⱼ` (the axes meet at `arccos(−1/3) ≈ 109.47°`), so
`L = Pᵢ ∩ Pⱼ` is a line. There is a unique `u ∈ T` of order 2 with
`u(Kᵢ) = Kⱼ`, `u(Kⱼ) = Kᵢ` (the double transposition `(ij)(kl)`), a 180°
rotation about an axis `b`. Then `u(L) = L`. A 180° rotation maps a line to
itself only if the line is `b`, or meets `b` orthogonally; the second case holds
here — verify in coordinates once, with `a₁=(1,1,1)`, `a₂=(1,−1,−1)`,
`b = x`-axis, giving `L = {(c, s, −s)}`, direction `(0,1,−1) ⊥ b`, meeting `b`
at `(c,0,0)`. So `u|_L` is the **point reflection about `(c,0,0)`**.

**(c) Chords.** A convex closed curve meets a line in at most two points
(generically zero or two). So `Kᵢ ∩ L` is an interval `Iᵢ`'s endpoint pair, and
`Iⱼ = −Iᵢ` under the reflection in (b). Two disjoint convex closed curves in
distinct planes are linked iff their chords **interleave**, and unlinked iff the
chords **nest** or are **disjoint**. If `Iᵢ = [a,b]` then `Iⱼ = [−b,−a]`; nesting
needs `a+b ≥ 0` and `a+b ≤ 0`, so `a+b=0`, so `Iᵢ = Iⱼ` and the curves meet.
**Nesting is unavailable.**

**(d) Both survivors fail.** `T` is 2-transitive on `{1,2,3,4}`, hence transitive
on the six unordered pairs, so every pair is in the same case.
- *All interleaved*: every `lk(Kᵢ,Kⱼ) = ±1 ≠ 0`, contradicting §5.1.
- *All disjoint*: the convex disc `Dᵢ ⊂ Pᵢ` bounded by `Kᵢ` meets `Pⱼ` only in
  the filled chord, which misses `Kⱼ`; so `Dᵢ` misses every other component and
  `Kᵢ` splits off. Every 3-sublink is split, hence not `B`. ∎

**Cross-check already in hand:** a sweep of 132 convex-planar configurations
produces exactly these two outcomes and no third. Mention in one sentence as a
consistency check on the proof, not as evidence for it.

### 5.5 Convexity is essential — **remark, needs care**
If `Kᵢ` is planar but not convex, `Kᵢ ∩ L` is `2k` points with `k ≥ 2`, and the
reflection constraint no longer forbids nesting: `Iᵢ = [−3,−2] ∪ [1,4]` reflects
to `[−4,−1] ∪ [2,3]`, and each component of one nests inside a component of the
other. **The mechanism of 5.4 fails.** Say exactly that — do *not* say the
planar case is possible, which we have not shown, and do not say it is
impossible, which we have no reason to believe.

### 5.6 Triple Milnor invariants under the symmetry — **settled**

Previously flagged as the riskiest item. It is now closed, and the orientation
bookkeeping that made it risky turns out to be unnecessary.

**The orientation signs can all be taken `+1`.** A symmetry `g` acts on
components by a permutation and, for each component, either preserves or
reverses its chosen orientation; call that sign `εᵢ(g)`. The whole assignment is
an equivariant `±1`-bundle over the components, and over a transitive `G`-set
`G/H` such bundles are classified by `Hom(H, ±1)`. Here `H = Stab_T(Kᵢ) ≅ C₃`,
which has **odd order**, so `Hom(H, ±1)` is trivial, the bundle is trivial, and
orientations can be chosen equivariantly. Hence `εᵢ(g) = +1` throughout and

`μ̄(σi, σj, σk) = μ̄(i, j, k)` for every `σ ∈ T`.

That is the whole lemma. No branches, no case analysis. *(The same argument
covers `C₄` in §8.2, where the stabiliser is trivial, and the icosahedral action
in §8.3, where it is `A₄`, whose abelianisation is `C₃` — odd again.)*

**The solution space.** `μ̄` is alternating, so it is determined by its four
values on the 3-subsets written in increasing order, `(x₀,x₁,x₂,x₃)` with
`x₀ = μ̄(1,2,3)`, `x₁ = μ̄(0,2,3)`, `x₂ = μ̄(0,1,3)`, `x₃ = μ̄(0,1,2)`. Imposing
invariance under all 12 elements leaves a **1-dimensional** space, spanned by

`(x₀, x₁, x₂, x₃) = (−1, +1, −1, +1).`

So condition (i), which forces `|μ̄| = 1` on every triple, is satisfiable, and
the four signs are determined up to one global sign. This is Proposition B, and
it agrees with the hand derivation.

Computed by `milnor-symmetry.mjs` in this directory; the same script reports the
`C₄` case of §8.2 (also 1-dimensional, spanned by `(1,1,1,1)`).

### 5.7 The Brunnian contrast — **done, solid**
For a 4-component Brunnian link, the longitude `ℓ₄` lies in the multilinear
weight-3 part of the free Lie algebra on `x₁,x₂,x₃`, which is 2-dimensional with
basis `u = [[x₁,x₂],x₃]`, `v = [[x₁,x₃],x₂]`. The 3-cycle `x₁→x₂→x₃→x₁` sends
`u ↦ v − u`, `v ↦ −u`; in that basis the matrix is `[[−1,−1],[1,0]]`, with
characteristic polynomial `λ² + λ + 1`. No eigenvalue `+1` or `−1`, so the fixed
and anti-fixed subspaces are both zero, and every length-4 Milnor invariant
vanishes. Hence the standard 4-component Brunnian links admit no symmetry fixing
one component and cycling the other three.

Needs: a clean statement of why conjugation (basepoint movement) acts trivially
on `Γ₃/Γ₄`, and why `εᵢ` only contributes an overall sign. Both are standard but
must be written.

## 6. The proof: constructive (decided)

**What we have now.** Each 3-sublink has all three linking numbers zero, a
6-crossing diagram, and the Jones polynomial of `B`, agreeing to the last
coefficient across four independent projections.

**Why that is not a proof.** It pins the sublink down only by appeal to the
classification of 6-crossing links — a table lookup — and the Jones polynomial
is not a complete invariant. A referee is entitled to a self-contained argument.

**Decision: build the link so that each triple is visibly `B`, and prove it
directly.** No computer in the proof. The computations stay in the repo as a
check on the construction, and are mentioned in the paper only as that.

### What a constructive proof has to supply

By §5.2 the four triples are one `T`-orbit, so **one triple proves all four.**
That is the whole reason this is tractable. The argument has to be:

1. **Localise.** Show that the three components meeting at vertex `v₄` interact
   only inside a ball `B(v₄)` around that vertex — i.e. outside the four vertex
   balls, the four components are pairwise disjoint in a controlled way and no
   crossings occur between the *relevant* pairs. This is where the design work
   is: the link must be built so the statement is true and visibly so.
2. **Identify the local picture.** Inside `B(v₄)`, exhibit the three strands as
   the standard Borromean weave — the 6-crossing alternating diagram, 2
   crossings per pair, cyclic over/under.
3. **Kill the rest.** Show each component's remaining arc, outside the three
   vertex balls it participates in, can be isotoped away without crossing
   anything — e.g. it lies in a ball disjoint from the other two components of
   that triple, or bounds a disc meeting nothing.
4. **Assemble.** Steps 1–3 give an ambient isotopy of the 3-sublink onto the
   standard diagram of `B` from §2.5.

### What that implies for the geometry — this is the real work

The link we currently have was *found by search and then relaxed*. It is not
built to make the above true, and step 1 may simply fail for it. Expect to
**redesign the component** so that:

- each component passes near exactly three of the four vertices (the three
  vertices of its own face), and is far from the fourth;
- near each vertex the three incoming strands are in "standard position" — three
  arcs forming a small triangle with alternating over/under;
- the arcs connecting one vertex region to the next stay in a collar where they
  meet nothing.

This is a design constraint, not a search criterion, and it is likely to produce
a *cleaner* link than the one we have — plausibly with fewer crossings.

**Checkpoint:** before writing any prose, produce a component for which step 1
is true and verifiable, and confirm with the existing machinery that all four
sublinks are still Borromean. If the redesign fails after a fair attempt, fall
back to printing a Reidemeister sequence — but do not start there.

### Bonus the constructive route buys

If the proof is local — "a Borromean weave at each vertex, nothing elsewhere" —
then it does not actually care that the polyhedron is a tetrahedron. It cares
that **every vertex meets exactly three faces.** So the same proof should give
the cube and the dodecahedron for free, which is §8.3.

## 7. The explicit model the paper prints — **highest-value work item**

The smooth link is 4 × 180 floating-point points. That is not a model a paper
can state, and not one a reader can check.

**The 6-corner polygonal model is the right object.** Each component is a closed
hexagon; the whole link is 24 points; and by §5.3 the entire configuration is
generated by **two** points. A paper can print two points.

**Action: find a model with rational coordinates.** The group acts by signed
coordinate permutations in the `(1,1,1)` frame — the 3-fold rotation is
`(x,y,z) ↦ (z,x,y)` and the half-turns are sign changes — so rational input
gives rational output, and *every crossing is then decided by exact arithmetic*.
A polygonal link with rational vertices has a diagram that is a **theorem**, not
a floating-point measurement.

Concretely:
1. Round the two optimised corners to nearby rationals with small denominators.
2. Re-verify exactly: crossings by rational arithmetic, over/under by comparing
   rationals, pairwise `lk` combinatorially, and the sublink identified by
   Route A or B.
3. Report the model as a table of two points plus the group action.

This removes floating point from the paper's claims entirely, and it is the
single change that most improves the paper's standing. **Do this before writing
the results section.**

Current best starting point: the optimised 6-corner arc, strand separation
`0.109` in model units with the link about 2.5 across — enough slack that
rational rounding will not break it.

## 8. Adjacent problems — the author's shortlist

Five, chosen by the author. Not committed to the paper; at most one or two get a
paragraph. The rest are sequels.

### 8.0 Vocabulary first, because two of these need it

**Linking number** counts how many times one loop passes through another, with
sign. It is the crudest measure of "are these two hooked together". For the
Borromean rings it is **0** for all three pairs — which is exactly the point:
they are inseparable and the linking number cannot see it.

**Milnor's triple invariant** `μ̄(i,j,k)` is the next thing up. It is an integer
that detects *three-way* linking that no pairwise number can. It is defined only
once all the pairwise linking numbers vanish (otherwise it is ambiguous). For
the Borromean rings `μ̄ = ±1`; for three completely unlinked loops `μ̄ = 0`. There
is a whole ladder: length-4 invariants `μ̄(i,j,k,l)` detect four-way linking that
survives when all the triples vanish, and so on upward.

**"Obstructed"** means: we can *prove* the thing does not exist, because the
symmetry forces an invariant to be zero while the object we want requires it to
be non-zero. It is a proof of impossibility, not a failed search. Worth being
precise about, because an obstruction at one rung of the ladder says nothing
about the rungs above it — which is exactly the situation in §8.4.

### 8.1 Planar components without convexity

Can all four components be planar? §5.4 forbids it when they are also convex,
and §5.5 shows the only argument we have evaporates without convexity: a
non-convex planar curve meets the key line in four or more points, and
point-reflected interval systems can then nest.

Status: **open, and I would guess possible.** The cheap experiment is to run the
existing search restricted to planar, `r₁`-invariant, non-convex curves — a
3-fold-symmetric star-shaped curve in each plane perpendicular to a 3-fold axis.
That is a two-parameter family on top of what `scan.mjs` already does.

### 8.1b Three kinds of symmetry, which must not be run together

Everything below depends on keeping these apart. They are different questions
with different answers.

| | what it is | what indexes the components |
|---|---|---|
| **Cyclic**, `C_n` | one rotation axis, components in a single cycle | positions round a circle |
| **Face-polyhedral** | one component per **face** of a polyhedron whose every vertex meets exactly three faces; a Borromean weave at each **vertex** | faces |
| **Other transitive actions** | a polyhedral *group* permuting `n` objects that are not faces | whatever the objects are |

Our theorem is face-polyhedral, on the tetrahedron. The author's rosette figures
are cyclic. The two coincide nowhere except by accident.

### 8.2 Cyclic ("circular") symmetry, and which `n` admit it

The question: for which `n` is there an `n`-component link with a **cyclic**
symmetry `C_n` — a single rotation axis, components permuted in one cycle — such
that every 3-component sublink is `B`? Nothing here refers to faces or vertices.

**First, a correction to the premise.** The 5-circle and 7-circle rosette images
are examples of *cyclic symmetry*; they are almost certainly **not** examples of
our property, because they are built from **round circles**, and the Borromean
rings provably cannot be built from three round circles (Freedman–Skora 1987;
Lindström–Zetterström). Those pictures show the symmetry we want on an object
that does not have the linking we want. In any construction here, the components
cannot be geometric circles.

**What the symmetry costs, by `n`.** The number of conditions is the number of
`C_n`-orbits of 3-subsets:

| `n` | 3-subsets | orbits under `C_n` | conditions |
|---|---|---|---|
| 4 | 4 | 1 | **1** |
| 5 | 10 | 2 | 2 |
| 6 | 20 | 4 | 4 |
| 7 | 35 | 5 | 5 |

**`n = 4`, `C₄`: no obstruction.** Orientations are equivariant by §5.6 (the
stabiliser is trivial), so `μ̄` is simply `C₄`-invariant, and the solution space
is 1-dimensional, spanned by `(1,1,1,1)` — all four triples can be Borromean.
Verified in `milnor-symmetry.mjs`. **This is the cheapest open question on the
page**, a single condition, and it is genuinely not answered by our theorem:
`A₄` has no element of order 4, so our link has no 4-fold symmetry.

**`C₄` is not a strengthening of this paper's result.** `C₄` has order 4 and `T`
has order 12, and neither contains the other: a link can have a 4-fold axis and
no tetrahedral symmetry, or the reverse. So `n = 4` here is a *sideways*
question, asking for a different symmetry rather than more of the same one. It
is still the cheapest thing on this list to attack.

**`n = 6`, `C₆`:** four conditions. One of the four orbits (`{0,2,4}`, `{1,3,5}`)
is stabilised by a 3-fold rotation, which is harmless — the Borromean rings have
exactly that symmetry themselves. No obstruction identified. Strictly harder than
`n = 4`; do `n = 4` first.

**`n = 5`:** two conditions, and the author's hand-drawn 5-component diagram is
a proposal for it. Worth checking directly: it is a drawing, so it can be typed
in as a PD code and tested with the existing machinery.

### 8.3 Face-polyhedral symmetry — which `n`

**This is our construction, generalised, and it has nothing to do with §8.2.**
One component per face; every vertex meets exactly three faces; a Borromean
weave at each vertex.

A polyhedron whose every vertex meets three faces (a *simple* or 3-valent
polyhedron) with `F` faces has `V = 2F − 4` vertices and `E = 3F − 6` edges.
Two separate requirements:

- **(a) such a polyhedron exists with `n` faces.** True for every `n ≥ 4`.
- **(b) its rotation group is transitive on faces**, so the components are all
  equivalent, the conditions collapse into orbits, and one component generates
  the link. True only for the **tetrahedron (4), cube (6), dodecahedron (12)** —
  the Platonic solids with 3-valent vertices.

**`n = 5`: (a) yes, (b) no — so face-polyhedral symmetry is not available.** The
3-valent polyhedron with 5 faces is the triangular prism (2 triangles, 3
squares, 6 vertices). Its faces fall into **two orbits**, and its rotation group
is only `D₃`, order 6. So the components cannot all be equivalent, there is no
single generating component, and the symmetry does not do the work it does for
us. *The author's conclusion stands.* (My earlier claim that the dodecahedral
compound rescues `n = 5` was wrong — see the aside below.)

**Where the tetrahedron is genuinely unique.** "Every triple of components is a
vertex" means `C(n,3) = 2n − 4`, i.e. `n(n−1) = 12`, i.e. **`n = 4` and nothing
else** (checked to `n = 20`). For every other `n` the vertex-triples are a
strict subset of all triples:

| solid | faces `n` | vertices | `C(n,3)` | every triple a vertex? | face-transitive |
|---|---|---|---|---|---|
| tetrahedron | 4 | 4 | 4 | **yes** | yes |
| triangular prism | 5 | 6 | 10 | no — 6 of 10 | **no** |
| cube | 6 | 8 | 20 | no — 8 of 20 | yes |
| dodecahedron | 12 | 20 | 220 | no — 20 of 220 | yes |

So at `n = 6` the cube delivers **"the eight vertex-triples are Borromean"**,
which is weaker than and different from "every triple is Borromean". Do not
conflate them. If §6's constructive proof is genuinely local it gives the cube
version for free, since all it uses is three faces per vertex.

### 8.4 Mirror symmetry: `T_d` rather than `T`

`T_d ≅ S₄`, order 24, is the full symmetry group of the tetrahedron: the twelve
rotations we already have, **plus twelve orientation-reversing operations**
(reflections and rotary reflections). Unlike cyclic symmetry, this is a genuine
strengthening — `T ⊂ T_d` — so it asks whether the construction can be improved,
not replaced.

**What it demands.** A reflection reverses handedness, so a `T_d`-symmetric
embedding must be carried onto *itself* by a mirror, not merely onto something
isotopic to it. Every crossing is exchanged with its opposite somewhere in the
picture.

**Why it is not obviously impossible.** The Borromean rings are amphichiral —
equal to their own mirror image — so the local weave at each vertex can survive
a reflection. Nothing in §5.6 rules it out either: a reflection negates `μ̄`, and
the solution space there is 1-dimensional and spanned by `(−1,1,−1,1)`, so the
reflected assignment is the same one up to the global sign that §5.6 already
leaves free.

**Why the current link almost certainly does not have it.** The components are
corrugated with a handedness chosen by the search; nothing forced it to be
mirror-symmetric. Checking is cheap — reflect the coordinates in a mirror plane
of the tetrahedron and test whether the resulting point set is the original.

**Status.** Open. §8.7 decides it outright: if the link's symmetry group has
order exactly 12, `T_d` is impossible for this link, though possibly available
for a different one satisfying the same two conditions.

### 8.5 The Brunnian version

**The question.** Four components, tetrahedral symmetry, and removing any one
makes the other three fall *completely apart* (three unlinked loops) — rather
than leaving the Borromean rings. "Brunnian" is the standard word: every proper
sublink is trivial, but the whole thing is linked. The Borromean rings are the
3-component Brunnian link.

**What we can prove.** For a 4-component Brunnian link all the triple invariants
vanish by definition, so the first thing that can be non-zero is the **length-4**
Milnor invariant `μ̄(i,j,k,l)` — four-way linking. The standard 4-component
Brunnian links have it equal to `±1`. §5.7 shows a 3-fold rotation that fixes one
component and cycles the other three **forces every length-4 invariant to zero**
(the rotation acts on the relevant 2-dimensional space with characteristic
polynomial `λ² + λ + 1`, which has no eigenvalue `+1` or `−1`, so nothing is
fixed and nothing is anti-fixed). Tetrahedral symmetry contains such rotations.

**So: the standard 4-component Brunnian links cannot be given tetrahedral
symmetry.** That is a clean impossibility result, and it is the mirror image of
our main theorem — same solid, opposite answer.

**What it does not say.** It does not say no tetrahedrally symmetric 4-component
Brunnian link exists. A Brunnian link whose length-4 invariants all vanish, with
the linking only showing up at length 5 or beyond, is not touched by this
argument. Whether one can carry the symmetry is open.

### 8.6 Minimum crossing number

Our diagram reduces to 28 crossings. Two things worth having:
- a **lower bound**: each of the six pairs must weave through two different
  Borromean triples, which should force roughly 24; make it precise or drop it;
- whether the constructive link of §6 beats 28, which it plausibly will.

Only worth a sentence in the paper unless the bound is sharp.

### 8.7 The complement, and the maximum possible symmetry

See §12.2. One SnapPy run reports the largest symmetry group any drawing of this
link could have, which settles §8.4 outright and upgrades Theorem A from "here
is a symmetric representative" to a maximality statement. It says nothing about
§8.2, whose links need not have `T` at all.

### 12.1 Cyclic symmetry and mirror symmetry are unrelated questions

Two adjacent problems ask for a symmetry other than `T`, and they point in
different directions. An earlier draft ran them together; they are not the same
question and neither implies the other.

| | order | orientation | relation to `T` | asks |
|---|---|---|---|---|
| `C₄` (§8.2) | 4 | rotations | **neither contains the other** | a 4-fold axis, components in one cycle — a *different*, smaller symmetry |
| `T_d` (§8.4) | 24 | `T` plus 12 **reflections** | contains `T` | the same rotations plus mirrors — a genuine strengthening |

The practical consequences differ accordingly. A positive answer for `C₄` would
be a second theorem about a different symmetry; a positive answer for `T_d`
would improve this one. And §8.7 bears only on `T_d`, since it reasons about
*this* link, while `C₄` concerns links that need not have `T` at all.

### 12.2 "The complement", "hyperbolic", and why one computation settles §12.1

Written out from scratch, because the words are doing real work.

**The complement.** Take the link out of space and keep what is left over — all
the air around the strings, with four tunnels running through it where the loops
used to be. That leftover region is a space in its own right, and its shape is
determined by the link: deform the link without cutting it and the leftover
region deforms along with it, never tearing. So anything true about that shape
is a fact about the link.

**Hyperbolic.** Flat geometry is the one from school — angles in a triangle sum
to 180°, parallel lines stay the same distance apart. Hyperbolic geometry is a
consistent alternative where space curves away from itself everywhere: triangles
have *less* than 180°, and there is steadily more room the further out you go.
A crinkled lettuce leaf or a crocheted coral is a surface that has run out of
flat room and gone hyperbolic. The same thing exists in three dimensions, and
asking whether a space "is hyperbolic" asks whether distances can be measured
inside it according to those rules, consistently and all the way out.

For link complements the answer is usually yes. Thurston showed that apart from
a short list of understood exceptions, this is what link complements are like.

**Why hyperbolic is the useful case: it is rigid.** For a surface, being
hyperbolic leaves freedom — a donut-shaped surface can be given infinitely many
different flat geometries, long and thin or short and fat. In three dimensions
that freedom disappears. Mostow's rigidity theorem says that if such a geometry
exists at all, **there is exactly one of it.** No stretching, no squashing, no
choices. The leftover region has one true shape, the way a soap film spanning a
wire has one shape rather than a family of them.

**The payoff.** Because the shape is forced, every symmetry of the link has to
be a symmetry of that one rigid shape. Symmetries of a rigid object are finite
in number and a computer can enumerate them; SnapPy does it in seconds.

**What that buys for this paper.** At the moment the theorem says: *this
particular drawing* has twelve rotations. It leaves open whether some cleverer
drawing of the same link has more. The computation answers exactly that, because
it reports the symmetries of the link rather than of any one picture of it.

- If the answer is **exactly 12**, then no drawing does better. Theorem A
  strengthens from "here is a symmetric representative" to **"this is the most
  symmetric this link can be"**, and `T_d` (§8.4) is impossible *for this link*,
  since it has order 24.
- If the answer is **larger than 12**, better news: a more symmetric drawing
  exists and is worth finding.

Note what it does *not* settle: cyclic symmetry (§8.2) concerns links that need
not have `T` at all, so a result about this link says nothing about those.
